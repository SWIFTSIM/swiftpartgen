utils._extract_field_names(fields_d: dict, depth: int = 0) → list

Extract field names (keys of dict) into a list and return it. Ignores fields which are part of the _permitted_duplicate_field_names list. Do this recursively if you find a union or a struct.

Parameters:

fields_d (dict) – dict containing field names (keys) and their properties (values)

Returns:

field_names – list of field names in this dict

Return type:

list

utils.add_auxiliary_fields(contents_d: dict, id_checks: bool = True, part_struct_accessors: bool = False) → dict

Run through the read in contents (passed as contents_d) and add auxiliary fields, if necessary: - If a struct part does not exist, create one and put it in first position. - If we’re doing debug_id_checks for each struct, add that field to each substruct

Parameters:

  • contents_d (dict) – dict containing contents of read-in yml file to generate structs and fields from

  • id_checks (bool) – if True, add a field for IDs for each struct for debugging checks

  • part_struct_accessors (bool) – if True, add auxiliary fields needed for part struct accessors (offset/index in cell’s particle arrays for this particle, and pointer to cell_part_arrays)

Returns:

updated_contents_d: dict

Updated dict of particle fields

utils.check_output_directory(outdir: str | list, swift_header: bool = False, full_output: bool = False, testing: bool = False)

Extract the output directory from the parsed args. If it doesn’t exist, make it.

Parameters:

  • outdir (str or list) – (top level) output directory to write output into.

  • swift_header (bool) – If True, assume we’re writing files for SWIFT, not SWIFTGPUPACKSIM.

  • full_output (bool) – If True, we’re writing all files, not just (hydro) particles

  • testing (bool) – If True, we’re writing outputs for unit tests

Returns:

outdir – cleaned and verified output dir.

Return type:

string
